# Ex2.4 K_POINTS：三种给法和一套纪律

**本节目标：** k 点是 DFT 精度和效率的第一杠杆。QE 的三种给法各管一个场景，纪律只有一条：**收敛测试**。

## 1 三种给法

**① 自动网格（SCF/NSCF 主力）**

```fortran
K_POINTS automatic
  8 8 8  0 0 0     ! 三个数=网格密度，三个数=偏移(通常0)
```

**② 显式列表（Wannier 链 NSCF、特殊需求）**

```fortran
K_POINTS crystal
  64
  0.000 0.000 0.000  1.0
  0.125 0.000 0.000  1.0
  ...                ! 分数坐标 + 权重
```

**③ 路径模式（能带计算）**

```fortran
K_POINTS crystal_b
  5
  0.000 0.500 0.500  20   ! 起点及段内点数
  0.500 0.500 0.500  20
  0.500 0.250 0.750  20
  0.500 0.000 0.000  20
  0.000 0.000 0.000  1    ! 末点
```

`crystal_b` 会自动在段间均匀插值（数字=每段点数）——画能带的标配。

## 2 对应任务的记忆法

| 任务 | k 给法 | 为什么 |
|---|---|---|
| SCF | automatic | 布里渊区均匀采样 |
| NSCF（DOS/W90） | **crystal 显式完整网格** | 见下面纪律 |
| bands（能带图） | crystal_b 路径 | 沿高对称线采样 |
| post-processing | 与上游一致 | 读的是上游波函数 |

## 3 姊妹篇的老话：Wannier 链的完整网格纪律

`pw2wannier90` 链的 NSCF **必须用完整均匀网格、不做对称性约化**（&CONTROL 里 `nosym=.true., noinv=.true.`，k 点显式列出）：

- Wannier90 要在 k 点之间找**直接邻居**算重叠矩阵 `.mmn`——对称约化掉的点 = 邻居断裂 = mmn 错 = 全链崩；
- `.win` 的 `mp_grid` 必须与这个网格一致（LWTHW Ex3.2 的 mp_grid 警告，根源在此）；
- 姊妹篇 WT 书 Ex8.3 的"完整均匀网格"说的就是这页的事。

**现在你知道"为什么"了**：不是仪式感，是 mmn 的数据结构决定的。

## 4 收敛测试纪律

```bash
# 4 4 4 → 6 6 6 → 8 8 8 → 12 12 12
# 判据：总能变化 < 1 meV/原子（或你项目的预注册容差）
```

- 金属比绝缘体要求更密的网格（费米面结构）；
- 2D 材料 c 方向是真空，网格给 1；
- **每个新体系都要重测**，别人的参数只能当起点。

## 5 本节总结

- automatic（SCF）/ crystal 显式（NSCF/W90）/ crystal_b（能带），三种给法各管一摊；
- Wannier 链 NSCF = 完整网格 + nosym + noinv + 与 mp_grid 一致；
- 网格密度永远收敛测试，1 meV/原子 判据起步。

## 师兄提醒

!!! warning "automatic 网格的偏移陷阱"

    `automatic` 最后三个数是 Γ 点偏移。偶数网格不偏移则含 Γ；偏移 (1 1 1) 则不含。**SCF 和后续 NSCF 的偏移必须一致**，混用时能量对不上、密度文件读进来也悄悄错。建议：非必要不偏移，保持 Γ 居中。
