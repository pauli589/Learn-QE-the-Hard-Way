# Ex2.3 &ELECTRONS 块：SCF 收敛的艺术

**本节目标：** SCF 不收敛是 QE 日常的一半。这页给你收敛参数的完整工具箱和排查树。

## 1 常用参数

```fortran
&ELECTRONS
  conv_thr         = 1.0d-8   ! 收敛阈值：总能 Ry，总量（非每原子！）
  mixing_beta      = 0.7      ! 电荷混合系数
  mixing_mode      = 'plain'  ! 或 'TF'/'local-TF'（金属大体系用）
  electron_maxstep = 100      ! 最大步数（默认 100）
  diagonalization  = 'david'  ! 'david'/'cg'/'ppcg'
/
```

## 2 conv_thr：多大的数算"收敛"

- **默认 1e-6 Ry**：粗算了事；
- 结构优化前 SCF：**1e-8** 以上（否则力噪声大于力本身，原子乱动）；
- 含 phonon 的链：更严；
- 换算手感：1e-8 Ry ≈ 0.14 meV **总量**——除以原子数才是每原子精度。

**纪律：** `conv_thr` 要和下游任务匹配。弛豫配 1e-6 的 SCF = 力全是噪声 = "优化不收敛"玄学问题的第一根源。

## 3 SCF 不收敛：排查树

```
SCF 迟迟不收敛（电子_maxstep 用尽）
 │
 ├─ 金属/小带隙? → occupations smearing + degauss 给了吗（Ex2.2）
 │                  → mixing_beta 降到 0.3，或 mixing_mode='local-TF'
 ├─ 磁性体系? → starting_magnetization 给初值了吗（全 0 可能锁死在非磁解）
 ├─ 层状/真空体系? → mixing_ndim 加大(默认8→12)，或 dipole 修正
 ├─ 收敛震荡（能量锯齿）? → mixing_beta 减半再试
 └─ 突然发散（NaN）? → ecutrho/赝势匹配问题（Ex2.2）或结构有原子重叠
```

**调参顺序**：先查物理原因（smearing/磁性/结构），再动数值参数（mixing）。**顺序反了，参数调好了物理还是错的。**

## 4 输出里看什么

SCF 每步输出（verbosity high）：

```
     iteration #  5
     total energy  = -15.84723412 Ry
     estimated scf accuracy <       3.2e-05 Ry
     ...
     convergence has been achieved in  12 iterations
```

盯三样：**estimated scf accuracy 的下降趋势**（应该稳定下降，锯齿=混合问题）、**total energy 稳定到小数后 6 位**、最终的 `convergence has been achieved`。最后还要扫一眼 `highest occupied, lowest unoccupied level`——带隙合理性和费米能参考（E_FERMI 的源头，姊妹篇 WT 书 Ex2.2 提过）。

## 5 本节总结

- `conv_thr` 是总量不是每原子，弛豫任务 ≥1e-8；
- 不收敛先查物理（smearing/磁性/结构），再调 mixing；
- 输出盯趋势、盯费米能附近。

## 师兄提醒

!!! warning "别把 mixing_beta 当万能药"

    `mixing_beta=0.1` 能让大部分难收敛体系"收敛"——但也可能收进一个错误的局部解（尤其磁性体系）。**收敛了不等于收敛到基态。** 难体系收敛后，换一组初值（starting_magnetization）重跑验证能量不更低，才算数。

## 练习

1. 对 Si 跑 SCF，把 conv_thr 从 1e-6 改到 1e-8，对比总能差多少、迭代数多几步。
2. 找一个金属体系（或人为调 degauss），体验 smearing 对收敛的影响。
