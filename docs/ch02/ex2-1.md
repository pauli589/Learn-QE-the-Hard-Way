# Ex2.1 &CONTROL 块：你要干什么

**本节目标：** 逐参数吃透 &CONTROL——QE 任务的总开关区。常用参数十来个，但每个都有"默认值陷阱"。

## 1 全景

```fortran
&CONTROL
  calculation  = 'scf'        ! 任务类型
  prefix       = 'si'         ! 工作目录身份证（Ex1.3）
  outdir       = './tmp'
  pseudo_dir   = './pseudo'   ! 赝势目录
  verbosity    = 'high'       ! 输出详细度
  tprnfor      = .true.       ! 打印力
  tstress      = .true.       ! 打印应力
/
```

`verbosity='high'` + 力 + 应力**建议常开**：多打几行日志不花钱，缺信息重跑 SCF 才贵。

## 2 calculation：八种任务，先认四个

| 值 | 干什么 | 读什么 | 之后可接 |
|---|---|---|---|
| `'scf'` | 自洽 | 无（从零） | 一切 |
| `'nscf'` | 非自洽（改 k 点重解） | SCF 密度 | dos.x/projwfc.x |
| `'bands'` | 能带（路径 k） | SCF 密度 | bands.x/plotband.x |
| `'relax'` | 原子弛豫（固定晶胞） | 无 | scf 重启 |
| `'vc-relax'` | 弛豫+变胞 | 无 | scf 重启 |
| `'md'` | 分子动力学 | — | 本书不覆盖 |

**scf → nscf / bands 的接力关系**是 QE 工作流的主干（Ex1.3 的 prefix 机制）：

- `nscf`：密度不变，换 k 网格（比如上均匀密网格）→ 算 DOS/PDOS/给 Wannier90 喂料；
- `bands`：密度不变，走高对称路径 → 画能带。

**nscf 和 bands 的区别就一条：k 点的取样方式。** 别背口诀，理解这句就够。

## 3 其他常用参数

| 参数 | 作用 | 提醒 |
|---|---|---|
| `restart_mode` | `'from_scratch'`（默认）/`'restart'` | 断点续算用 |
| `disk_io` | 中间量写盘频率 | `'low'` 省盘；W90 链要确保波函数可写 |
| `nosym` / `noinv` | 关对称性 | **Wannier 链 NSCF 必开**（Ex4.4） |
| `wf_collect` | 收集波函数到 outdir | 老版本 W90 接口相关，新版本默认行为已变 |

## 4 默认值陷阱清单

1. `pseudo_dir` 默认为空 → 赝势找不到（除非设了环境变量 `ESPRESSO_PSEUDO`）；
2. `verbosity` 默认 `'low'` → 很多信息不打，你以为没算；
3. `disk_io` 新版本默认 `'low'` → 波函数不落盘，`pp.x` 找不到东西。

**对策：** 你的项目模板里把这三项写死，永远显式。

## 5 本节总结

- &CONTROL = 任务类型 + 身份证 + 文件路径 + 输出开关；
- `scf→nscf/bands` 接力是主干，prefix 是钥匙；
- 三个默认值陷阱：pseudo_dir、verbosity、disk_io。

## 师兄提醒

!!! note "把 &CONTROL 模板化"

    建一个你自己的 `CONTROL.template`，把 prefix/outdir/pseudo_dir/verbosity 全写好，每次只改 `calculation`。QE 输入文件 80% 的低级错误（路径、引号、漏斜杠）都出在这个块——模板化之后这类错误终身绝育。
