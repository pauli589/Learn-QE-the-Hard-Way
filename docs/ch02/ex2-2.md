# Ex2.2 &SYSTEM 块：体系是什么

**本节目标：** &SYSTEM 是参数最多、坑最深的块。本页只讲高频参数和它们的"为什么"。

## 1 结构信息：两条路

**路 A：`ibrav` 整数选格子**（QE 约定 1-14 对应常见 Bravais 格子）

```fortran
&SYSTEM
  ibrav = 2           ! 2 = fcc（Si 金刚石结构的惯用写法）
  celldm(1) = 10.20   ! 晶格常数 (bohr)
  nat = 2
  ntyp = 1
/
```

**路 B：`ibrav=0` + `CELL_PARAMETERS` 卡片**（自由格式，VASP 用户过渡友好）

```fortran
&SYSTEM
  ibrav = 0
  nat = 2, ntyp = 1
/
CELL_PARAMETERS angstrom
  0.00 2.715 2.715
  2.715 0.00 2.715
  2.715 2.715 0.00
```

**建议：一律用路 B。** ibrav 数字和 celldm 顺序是背了也会错的体系（1-14 谁记得住），ibrav=0 + 显式晶格 = 少一个记忆负担 + 和其他软件格式互通。代价是文件长两行，值。

## 2 电子结构三要素

```fortran
  ecutwfc  = 30     ! 波函数截断 (Ry)
  ecutrho  = 240    ! 电荷密度截断 (Ry)，默认 4×ecutwfc
  nbnd     = 10     ! 能带数
```

- **ecutwfc**：必须做收敛测试（Ex3.1 演示）；
- **ecutrho**：NC 赝势默认 4 倍即可；**USPP/PAW 赝势要求 8-12 倍**（看赝势文件头）——不升上去密度算错，错而不报；
- **nbnd**：默认 = 占据带数（绝缘体）。要算空带（DOS 图、Wannier 链）必须显式给：**占据 × 1.5 起步**。

## 3 smearing / occupations：金属 vs 绝缘体

```fortran
  # 绝缘体：
  occupations = 'fixed'      # 或不写（默认）
  # 金属 / 带隙小的体系：
  occupations = 'smearing'
  degauss = 0.01             # 展宽宽度 (Ry)
  smearing = 'gaussian'      # 或 mv (Marzari-Vanderbilt 冷积分)
```

- 展宽宽度要**收敛测试**（0.02 → 0.01 → 0.005，能量变化 < 1 meV/原子）；
- 金属体系 `degauss` 不收敛就出物理结论 = 给审稿人送分；
- Wannier 链的体系若有 smearing，注意能量参考问题（姊妹篇 WT 书 Ex2.2 的 E_FERMI 就来自这里）。

## 4 磁性与 SOC（Ex4.3 预告）

```fortran
  nspin = 2          # 自旋极化
  starting_magnetization(1) = 0.5
  lspinorb = .true.  # SOC（需全相对论赝势）
  noncolin = .true.  # 非共线（SOC 自动开启）
```

现在混个脸熟，Ex4.3 细讲。

## 5 本节总结

- 结构一律 `ibrav=0` + `CELL_PARAMETERS`；
- `ecutrho` 对 USPP/PAW 要 8-12×（头号暗坑）；
- `nbnd` 要算空带必须显式；smearing 参数要收敛。

## 师兄提醒

!!! warning "ecutrho 是 QE 新手的头号隐形杀手"

    换 USPP/PAW 赝势不升 `ecutrho`，SCF 照样"收敛"，力照样"小"——但密度和力的数值全是错的。**每次换赝势，第一件事打开 UPF 文件头看 `cutoff for rho` 推荐值**（grep 一下就有），抄进输入。这种错误不报错、不警告、只在你的物理结论里爆炸。

## 练习

1. 打开你项目用的赝势 UPF 文件头，找出 ecutwfc/ecutrho 推荐值，和你的输入对比。
2. 数一数你的体系占据带数应该是多少，检查 nbnd 给够没有。
