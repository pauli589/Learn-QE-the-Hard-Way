# Ex2.5 赝势：从哪下、怎么选、怎么验

**本节目标：** 赝势是 QE 里唯一"你替程序做的物理决定"。选对赝势 = 精度的一半。本页给你选型流程和验证清单。

## 1 QE 的赝势生态

| 来源 | 类型 | 特点 |
|---|---|---|
| **PSlibrary** (dal Corso) | PBE/PAW 为主 | 官方推荐首选，元素全 |
| **SG15** | ONCV NC | 精度高、可移植性好 |
| **PseudoDojo** | ONCV NC | 带精度测试报告 |
| SSSP 库 | 精选合集 | **新手闭眼用**：每个元素挑好+测好 |
| 自制 (ld1.x) | 任意 | 你项目的"定制 d-zeta"路线，进阶 |

**赝势类型速记：** NC（模守恒，软、ecutrho=4×）vs USPP（超软，需 8-12×）vs PAW（类似 USPP 的投影方法，QE 里表现同 USPP）。`*_rrkjus` = ultrasoft，`*_gipaw`/ONCV = NC，PSlibrary 的 `*_paw` 文件名里写着。

## 2 选型流程（三分钟版）

1. **先试 SSSP**：https://www.materialscloud.org/sssp ——按精度档（efficiency/precision）每元素给好了赝势+推荐截断，直接抄；
2. SSSP 没有或要统一来源 → PSlibrary（PBE, PAW）或 SG15（NC）**全体系用同一家**；
3. 记录：每个元素的 UPF 文件名+版本，写进输入同目录的 README。

## 3 拿到一个 UPF 先验三件事

```bash
grep -i "cutoff" Si.UPF         # 推荐的 ecutwfc / ecutrho
grep -i "z_valence" Si.UPF      # 价电子数 → 检查 NELECT 对不对
grep -i "functional" Si.UPF     # 交换关联泛函，必须和你 &SYSTEM 的 input_dft 一致
```

三个经典死法：

- **泛函不匹配**（PBE 结构用 LDA 赝势）：错而不报，物理全歪；
- **ecutrho 没按推荐值升**（USPP/PAW）：Ex2.2 讲过，头号隐形杀手；
- **价电子数想当然**：比如 Fe 的 PAW 是 8 价还是 16 价电子（含 3p 半芯），直接影响 NumOccupied/占据数——**grep z_valence，别背**。

## 4 与 VASP 的 PAW 对比

概念上 VASP 的 POTCAR ≈ QE 的 UPF，但**数据集完全不同，数值不可比**。跨软件对比能量只有相对量可比（能差、力、声子趋势），总能量绝对值毫无意义。这一点在复现工作（姊妹篇 WT 书）里反复出现：**换赝势 = 换物理模型的一部分，要显式记录并验证。**

## 5 本节总结

- 新手 SSSP，进阶 PSlibrary/SG15，全体系统一来源；
- UPF 三查：cutoff、z_valence、functional；
- QE 单位是 Ry，且换赝势=换模型的一部分，必须记录验证。

## 师兄提醒

!!! note "赝势测试的最小方案"

    正式体系换新赝势前，跑三个免费测试：① 伪态数目对不对（能带 vs 已知文献形状）；② ecut 收敛曲线；③ 一个已知小体系（如体相 Si 的带隙、晶格常数）的基准值。加起来不到一天机时，能防住 90% 的赝势事故——比论文返稿后重算全链便宜太多。

## 练习

1. 为你项目的体系列出 SSSP 推荐赝势和推荐截断，与现有输入对比。
2. 对比同一元素（如 O）的 NC 和 PAW 赝势文件头，找出两者 ecutrho 推荐值差异。
