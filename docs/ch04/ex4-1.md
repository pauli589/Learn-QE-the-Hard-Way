# Ex4.1 后处理工具全景

**本节目标：** QE 的后处理是"自带全家桶"——认识每个 `*.x` 的分工，你就有了完整的分析武器库。

## 1 全家桶地图

```
pw.x (SCF/NSCF/bands) 的产物（波函数/密度/本征值）
   │
   ├─ dos.x           → 总态密度          (si.dos.dat)
   ├─ projwfc.x       → 投影态密度+波函数投影 (Ex3.3)
   ├─ bands.x         → 整理能带数据       (Ex3.2)
   ├─ pp.x            → 导出电荷密度/势/波函数 → 可视化
   ├─ pw2wannier90.x  → Wannier90 接口    (Ex4.4)
   ├─ pw2gw.x         → 交给 BerkeleyGW 等
   └─ (ph.x 等        → 声子/电声，本书不覆盖)
```

## 2 pp.x：万能导出器

```fortran
&pp
  prefix = 'si'
  outdir = './tmp'
  outdir_plot = './plot'
  plot_num = 0          ! 导什么
  filplot = 'charge.cube'
/
```

`plot_num` 常用值速查：

| 值 | 导出什么 | 用途 |
|---|---|---|
| 0 | 电荷密度 | 成键分析、VESTA 可视化 |
| 1 | 体系总势 | 功函数（配合 planar average） |
| 2 | |ψ|²（加 `kpoint`/`band`/`spin` 选态） | 单波函数可视化 |
| 7 | 电荷密度差（`weight` 加权叠加） | 差分电荷 |
| 10 | 差分电荷（自旋） | 磁性体系 |

输出格式 `iflag=3`（Gaussian cube）+ VESTA 打开——**差分电荷图是论文的常客**， QE 用户不该求人。

## 3 后处理的通用心法

1. **所有后处理都从 prefix+outdir 读上游**——和主程序一样的钥匙机制；
2. **先查上游质量**：NSCF 的 k 网格、nbnd、能量窗不够，后处理再精致也是垃圾进垃圾出（姊妹篇 WT 书的整本书都在讲这个道理）；
3. **cube 文件别乱存**：一个波函数 cube 可以上百 MB，算完归档删掉。

## 4 本节总结

- dos/projwfc/bands/pp 是四大金刚，覆盖 90% 分析需求；
- pp.x 的 plot_num 是万能导出开关；
- 心法三条：prefix 钥匙、上游质量、大文件卫生。

## 师兄提醒

!!! note "后处理不产生新物理"

    后处理只是"换一种方式看已有结果"。**DOS 里的错误来自 NSCF 的 k 网格，差分电荷的错误来自 SCF 的赝势**——后处理层永远不是根因。排错时永远往上游走，这个直觉在 QE、Wannier90、WannierTools 三本书里是同一条主线。
