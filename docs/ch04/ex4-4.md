# Ex4.4 Wannier90 接口：工具链的总闸门

**本节目标：** `pw.x → pw2wannier90 → wannier90` 完整接口。这一页是三本书的连接点——姊妹篇的所有流程，源头在这。

> 下游细节：Wannier90 侧见 [LWTHW](https://pauli589.github.io/Learn-Wannier90-the-Hard-Way/)（尤其 Ex3.1-3.4、Ex4.4）；再下游 [LWTTHW](https://pauli589.github.io/Learn-WannierTools-the-Hard-Way/) Ex8.3 的材料链第一步就是本页。

## 1 四步流水线

```bash
# ① SCF（正常做，含 SOC 按需）
pw.x -in scf.in > scf.out
# ② Wannier 专用 NSCF：完整均匀网格，不给对称约化！
pw.x -in nscf_w90.in > nscf_w90.out
# ③ -pp 生成 .nnkp，再导矩阵
wannier90.x -pp seed
pw2wannier90.x -in pw2wan.in > pw2wan.out
# ④ wannierization（下游书的主场）
wannier90.x seed > w90.out
```

## 2 nscf_w90.in 的关键配置

```fortran
&CONTROL
  calculation = 'nscf'
  prefix      = 'si'
  outdir      = './tmp'
  pseudo_dir  = './pseudo'
  nosym       = .true.     ! ★ 三连：完整网格纪律
  noinv       = .true.     ! ★
  verbosity   = 'high'
/
&SYSTEM
  ...                      ! 同 SCF
  nbnd = 12                ! ★ 空带给足（W90 的候选带）
/
&ELECTRONS
  conv_thr = 1.0d-8
/
...（结构同 SCF）
K_POINTS crystal
  64                       ! ★ 显式完整网格（如 4×4×4 全列出）
  ...
```

三个 ★ 的"为什么"：

- **nosym/noinv + 显式 k**：`.mmn` 需要每个 k 点的直接邻居——对称约化会抽掉邻居，链就断了（Ex2.4 的完整网格纪律，这里是它的正式登场）；
- **nbnd**：W90 的 `num_bands` ≤ 这里的 nbnd；空带覆盖不足 = 解纠缠失败/能带插值错（姊妹篇翻来覆去讲的"空带覆盖"）；
- **网格与 `.win` 的 `mp_grid` 一致**：LWTHW Ex3.2 的警告源头。

## 3 pw2wan.in

```fortran
&inputpp
  prefix     = 'si'
  outdir     = './tmp'
  seedname   = 'seed'
  write_amn  = .true.
  write_mmn  = .true.
  write_unk  = .false.     ! 要画 Wannier 函数才需要
/
```

## 4 交接验收清单（上游合格证书）

把结果交给 Wannier90 之前，QE 端必须给出：

- [ ] SCF 收敛、赝势/泛函/截断记录在案；
- [ ] NSCF 网格 = `.win` 的 mp_grid，显式、无约化；
- [ ] `.nnkp` 的 k 点数与网格一致；`.amn` 无全零块；`.eig` 行数 = nbnd×nk；
- [ ] 能量参考记录：QE 输出的费米能（smearing 体系）/VBM（绝缘体）——**下游 W90/WT 的 E_FERMI 就抄这里**（姊妹篇 WT 书 Ex2.2 的 NELECT/NumOccupied 流程，其能量参考源头是本页）。

## 5 本节总结

- 四步链：SCF → NSCF(完整网格) → pw2wannier90 → W90；
- 三★配置（nosym/noinv、显式 k、nbnd）各有明确的技术根源，不是仪式；
- 交接四查是 QE 侧的"出厂合格证"，下游三本书全建立在它之上。
