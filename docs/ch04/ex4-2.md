# Ex4.2 二维材料与真空层

**本节目标：** 2D 计算（你项目的 TMD 就是这类）的特殊配置：真空层、偶极修正、层状校正。参数不多，但每个都影响结论。

## 1 真空层：多厚算够

```
结构 = 材料层 + 真空
c 方向：真空 ≥ 15 Å（层间相互作用 < 可忽略）
```

**验证方法（不是拍脑袋）：** c 从 15→20→25 Å 各算一遍 SCF，看目标性质（总能/带隙）是否收敛。你项目的交接记录里就有"c=19→25 Å 真空势与 VBM 同步移动、带隙几乎不变"的实测——那就是标准做法。

真空不够的症状：镜像层通过周期边界耦合，带隙/功函数悄悄偏移，**错而不报**。

## 2 偶极修正：非对称层状体系必开

上下表面不等价的体系（如单面官能化、非对称 TMD）层间会建立电场，需要 dipole correction：

```fortran
&SYSTEM
  dipfield = .true.
  edir     = 3            ! 沿 c
  emaxpos  = 0.85         ! 偶极面位置(分数坐标, 放真空区中间)
  eopreg   = 0.01
  eamp     = 0.0
/
```

对称体系（如 2H-TMD 双面 S）不需要。**要不要开，看结构对不对称，不看书本结论。**

## 3 2D 计算的三查

1. **c 方向 k 网格 = 1**（Ex2.4 的 Nk3=1，同一个道理的两端）；
2. **真空区没有高能态干扰**：`nbnd` 给足后，检查最高几条带是不是"真空态"（波函数弥散在真空区）——如果是，要么提真空层质量要么在下游分析时排除（姊妹篇 WT 书里"真空伪电荷混入高能流形"的坑，根源在此）；
3. **功函数/能级对齐**：2D 体系能级参考真空能级，`pp.x plot_num=1` + 平面平均拿真空势。

## 4 本节总结

- 真空 ≥15 Å 起步 + 收敛测试验证；
- 非对称体系开 dipole 修正；
- 2D 三查：Nk3=1、真空态混入、能级参考。

## 师兄提醒

!!! warning "真空态是 2D+Wannier 链的隐形地雷"

    真空区的高能"准自由电子态"会被投影分析误判、被 Wannier 窗口误吸。**处理原则：识别（波函数空间分布）、排除（分析时剔除或挪出窗口）、记录（写进计算档案）。** 姊妹篇项目花了大量任务处理"真空伪电荷"，你现在知道它的物理根源了——预防的成本远低于治疗。

## 练习

1. 对一个 2D 体系做 c=15/20/25 Å 的真空收敛测试。
2. 用 `pp.x plot_num=1` + 平面平均，亲手测一次功函数。
