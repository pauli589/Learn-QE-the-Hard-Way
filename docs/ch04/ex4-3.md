# Ex4.3 SOC 与磁性

**本节目标：** 自旋极化、非共线、SOC 的参数配置和它们之间的从属关系。拓扑/霍尔类计算（姊妹篇的主战场）的 QE 端配置全在这页。

## 1 三个开关的从属关系

```
nspin = 2            磁性（共线自旋极化）
      │
      └─ 非共线: noncolin = .true.
                │
                └─ SOC: lspinorb = .true.  (自动隐含 noncolin)
```

**记忆法：SOC ⊃ 非共线 ⊃ 共线磁性的参数集，一层比一层多。**

## 2 共线磁性（nspin=2）

```fortran
&SYSTEM
  nspin = 2
  starting_magnetization(1) = 0.5    ! Fe 的初磁矩（0~1 的比例）
/
&ELECTRONS
  conv_thr = 1.0d-8
/
```

- **初磁矩必须给**：全 0 起步可能锁死在非磁解；
- 铁磁/反铁磁：AFM 靠不同原子的 `starting_magnetization(1) = +0.5 / (2) = -0.5`；
- 终态磁矩看输出 `total magnetization` 和每个原子的磁矩（ verbosity high）；
- `occupations='smearing'` 几乎必配（磁性体系总有金属性能带）。

## 3 SOC（lspinorb）

```fortran
&SYSTEM
  lspinorb = .true.        ! 全相对论赝势必须有！
  nbnd     = ...           ! 能带数翻倍
/
```

**三个硬前提：**

1. **赝势必须全相对论（fully relativistic）**——UPF 文件头 `relativistic="full"`。普通标量赝势 + lspinorb = 报错或静默无 SOC（看版本），**换 SOC 计算前先 grep 赝势**；
2. 能带数语义变化：非共线下每条带单自旋占据，**nbnd 和占据数计算规则都翻倍**（NumOccupied 的数法变化，姊妹篇 WT 书 Ex4.1 讲过）；
3. 收敛更慢，`conv_thr` 别放松。

## 4 与姊妹篇的接口

| 本页配置 | 对应下游 |
|---|---|
| `lspinorb` + W90 链 | WT 书 Ex5.1 的非共线 wannierization 前置 |
| `nspin=2` + W90 链 | WT 书 Ex4.1 的 E_FERMI 场景（QE 输出的费米能填进 wt.in） |
| 非磁+SOC | OHC 教程链（WT 书 Ex7.1 的 WS₂ 例子是含 SOC 的） |

**你项目的 QE 链就是"非磁结构 + SOC + 完整 k 网格 + W90"**——本页 + Ex4.4 = 你的日常。

## 5 本节总结

- 开关从属：SOC ⊃ 非共线 ⊃ 共线；一层一层加，别跳级；
- SOC 硬前提：全相对论赝势 + nbnd/占据语义翻倍；
- 磁性初值必给，收敛后验磁矩。

## 师兄提醒

!!! warning "SOC 打开后一切验收重做"

    开 SOC 前验收过的东西（能带形状、k 收敛、DOS）全部作废——自旋简并劈裂后，收敛行为、特征能量全变。**把 SOC 开关当成"换了一个软件"来对待**：所有收敛测试重跑一轮。这是姊妹篇磁性体系验收清单（WT 书 Ex5.1）在 QE 端的根。
