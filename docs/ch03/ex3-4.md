# Ex3.4 结构优化：relax 与 vc-relax

**本节目标：** 弛豫是所有计算的起点（结构不对全白算）。QE 的两种弛豫、收敛三判据和常见陷阱，一页讲完。

## 1 两种弛豫

```fortran
calculation = 'relax'      # 只动原子（晶胞固定）
calculation = 'vc-relax'   # 原子 + 晶胞（cell_dofree 可限制）
```

配套参数（&CONTROL 里）：

```fortran
  forc_conv_thr = 1.0d-4    # 力收敛 (Ry/bohr)
/&ELECTRONS 里另加:
  etot_conv_thr = 1.0d-5    # 能量收敛 (Ry)
  press_conv_thr = 0.5      # 压力收敛 (kbar)，vc-relax 用
/
```

**三判据同时满足才算收敛**（力 + 能量 + [压力]）。

## 2 实战要点

**① 先优化晶格常数再优化内部坐标**（或直接 vc-relax 一步到位，但大体系贵）；

**② 弛豫完成后必须接一次干净 SCF**：

```
vc-relax 结束时的密度/晶胞是"过程中的最后一步"
→ 用 CONTCAR…不对，QE 是把最终 ATOMIC_POSITIONS/CELL 抄出来
→ 写成新 scf.in 再跑一次 → 这才是"弛豫后体系"的干净结果
```

QE 不会自动帮你把最终结构存成优雅格式——**手抄 pw.x 输出里 `Begin final coordinates` 之后的那段**（输出会贴心地给最终 CELL_PARAMETERS 和 ATOMIC_POSITIONS，直接可复制进新输入）。

**③ 力的验收**：`force norm` 低于 `forc_conv_thr`；对称结构（如 Si 原胞）的力应严格为零——不为零说明有数值问题。

## 3 常见陷阱

| 症状 | 原因 | 药方 |
|---|---|---|
| "convergence NOT achieved"（离子步） | SCF 内层没收敛好（conv_thr 太松） | 内层 conv_thr ≤ 1e-8（Ex2.3 的纪律） |
| 力振荡不收敛 | 结构太差起步 / ecut 不够 | 先粗优化，或提 ecut |
| vc-relax 晶胞乱漂 | 对称性太高，数值噪声驱动 | `cell_dofree='ibrav'` 保持格子形状，或先固定形状只优化体积 |
| 优化完和实验晶格常数差 1-2% | PBE 的正常误差 | 换实验常数算性质或接受 ~1% 系统差，**别调参硬凑** |

## 4 和 VASP 的对照

- `relax` ≈ VASP `IBRION=2`；`vc-relax` ≈ `ISIF=3`；
- QE 弛豫的力判据默认比 VASP 严格（单位还不同：Ry/bohr ≈ 25.7 eV/Å，**看数值前先换算**）；
- VASP 有 CONTCAR 自动落盘，QE 要手抄 final coordinates——习惯差异，不是缺陷。

## 5 本节总结

- relax（动原子）/ vc-relax（动+变胞），三判据收敛；
- 弛豫后必须干净 SCF 复跑一遍；
- `final coordinates` 手抄是 QE 的仪式感，别嫌烦。

## 师兄提醒

!!! warning "弛豫的起点很重要"

    从一个原子间距荒谬的结构直接 vc-relax，容易掉进奇怪的局部极小（原子对穿、键断裂）。**起步结构的合理性检查（键长 vs 共价半径和）只要两分钟**，能省掉"弛豫三天结果是个非晶"的事故。你项目里那些"结构修复攻坚"的交接报告，就是这个坑的实录。

## 练习

1. 故意把 Si 的一个原子挪离平衡 0.1 Å，跑 relax，验证力收敛和末态回到对称位。
2. 跑 vc-relax 得到 Si 晶格常数，与实验值 5.43 Å 对比，感受 PBE 的系统误差方向。
