# Ex3.1 SCF 实战：跑通第一个硅

**本节目标：** 完整敲出 Si 的 SCF 输入并跑通——全书第一个实战，之后所有任务都是它的变奏。

## 1 完整输入（逐行注释）

```fortran
&CONTROL
  calculation  = 'scf'
  prefix       = 'si'
  outdir       = './tmp'
  pseudo_dir   = './pseudo'
  verbosity    = 'high'
  tprnfor      = .true.
  tstress      = .true.
/
&SYSTEM
  ibrav        = 0
  nat          = 2
  ntyp         = 1
  ecutwfc      = 30
  ecutrho      = 240        ! NC 赝势 4×；USPP/PAW 按文件头 8-12×
  occupations  = 'fixed'    ! Si 是绝缘体
/
&ELECTRONS
  conv_thr     = 1.0d-8
/
ATOMIC_SPECIES
  Si  28.0855  Si.pbe-n-rrkjus_psl.1.0.0.UPF
CELL_PARAMETERS angstrom
  0.00  2.715  2.715
  2.715  0.00  2.715
  2.715  2.715  0.00
ATOMIC_POSITIONS crystal
  Si  0.00  0.00  0.00
  Si  0.25  0.25  0.25
K_POINTS automatic
  8 8 8  0 0 0
```

对照前四章：每个参数你都认识。这就是"从零学"的好处——没有一行是抄来的。

## 2 跑

```bash
mkdir -p tmp pseudo
# 赝势放 pseudo/（从 SSSP 或 PSlibrary 下载）
pw.x -in scf.in | tee scf.out
```

## 3 输出验收清单

按顺序检查（养成固定顺序，形成肌肉记忆）：

```bash
grep -A2 "number of Kohn-Sham" scf.out    # ① 电子数: 8 (z_valence 4×2)
grep "number of k points" scf.out         # ② k 点数: 8×8×8 约化后 29 个（有对称性）
grep "convergence has been achieved" scf.out   # ③ 收敛标志
grep "!    total energy" scf.out          # ④ 最终总能 (Ry)
grep "highest occupied" scf.out           # ⑤ 带隙/VBM: Si 约 0.6 eV (LDA/PBE 值看赝势)
grep -A5 "forces" scf.out                 # ⑥ 力应≈0（对称结构）
grep -A3 "P=" scf.out | tail -1           # ⑦ 压力应≈0
```

**验收标准：** ①电子数对 ②网格对 ③收敛 ④⑤数值和文献量级一致 ⑥⑦接近零。

## 4 三个必做的小实验（15 分钟，做完全懂 Ex2 的参数）

1. **ecutwfc 收敛**：20→30→40→50 Ry，画 ΔE 曲线；
2. **k 网格收敛**：4³→8³→12³；
3. **故意拆坏**：把 prefix 改错跑 bands，看报错——认识错误长什么样。

## 5 本节总结

- 完整输入 = 前四章所有知识的拼装；
- 验收七查固定顺序，变成肌肉记忆；
- 三个小实验做完，&SYSTEM/&ELECTRONS 的参数不再是名词。

## 师兄提醒

!!! note "把你的 scf.in 存成模板"

    这个文件就是你以后所有 QE 计算的骨架。改结构、改元素、改任务，都是在这个骨架上小修。**命名存档（scf_Si_template.in），标注每段的改动点**——三个月后的新计算直接复制骨架，出错率骤降。
