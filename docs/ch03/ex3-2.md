# Ex3.2 能带：NSCF 与 bands 计算

**本节目标：** 在 SCF 基础上画 Si 的能带。QE 画能带 = 两步接力 + 两个后处理，链路比 VASP 长，走通一次就熟。

## 1 流程图

```
scf.in (scf)  →  密度存进 tmp/
     │
     ├─► bands.in (calculation='bands', 路径k)  → pw.x
     │        └─► 波函数+本征值存进 tmp/
     │              └─► bands.x  → si.band.dat (按k段整理)
     │                    └─► plotband.x / gnuplot 画图
     │
     └─(对照)  nscf.in + DOS  → Ex3.3
```

## 2 bands.in

```fortran
&CONTROL
  calculation = 'bands'
  prefix      = 'si'
  outdir      = './tmp'
  pseudo_dir  = './pseudo'
/
&SYSTEM
  ibrav = 0
  nat = 2, ntyp = 1
  ecutwfc = 30
  ecutrho = 240
  occupations = 'fixed'
/
&ELECTRONS
  conv_thr = 1.0d-8       ! bands 不做SCF迭代，但语法要写
/
ATOMIC_SPECIES
  Si  28.0855  Si.pbe-n-rrkjus_psl.1.0.0.UPF
CELL_PARAMETERS angstrom
  0.00 2.715 2.715
  2.715 0.00 2.715
  2.715 2.715 0.00
ATOMIC_POSITIONS crystal
  Si 0.00 0.00 0.00
  Si 0.25 0.25 0.25
K_POINTS crystal_b
  5
  0.000 0.000 0.000  20   ! G
  0.500 0.000 0.500  20   ! X
  0.500 0.250 0.750  20   ! W
  0.375 0.375 0.375  20   ! K
  0.000 0.000 0.000  1    ! G
```

**与 SCF 的差异只有三处**：`calculation='bands'`、K_POINTS 换 `crystal_b` 路径、（密度不变所以）k 网格随便换。prefix/outdir 指回 SCF 的仓库——这是 Ex1.3 prefix 机制的现场演示。

## 3 bands.x + plotband.x

```bash
pw.x -in bands.in > bands.out

cat > bandsx.in << EOF
&bandspp
  prefix  = 'si'
  outdir  = './tmp'
  filband = 'si.band.dat'
/
EOF
bands.x -in bandsx.in > bandsx.out

plotband.x    # 交互式: 输入 si.band.dat → 输出 si.band.ps/提示 gnuplot 范围
```

或者直接 gnuplot 画 `si.band.dat`（第一列 k 距离，第二列起能量）：

```gnuplot
plot 'si.band.dat' u 1:2 w l
```

## 4 验收

- [ ] 价带顶在 G 且简并（三支重合，Si 的 Γ25'）；带隙约 0.6 eV（PBE 半导体低估，正常）；
- [ ] 导带形状与文献/兄弟软件结果对照；
- [ ] **和 VASP/文献对比时：相对量可比（带隙、色散形状），绝对能量不可比**；
- [ ] k 路径坐标与标准表核对（WT 书 Ex2.5 的 Setyawan-Curtarolo 表）。

## 5 本节总结

- 能带 = bands 接力（读密度换 k 路径）+ bands.x 整理 + 画图；
- `crystal_b` 的数字是每段点数；
- 跨软件只比相对量，绝对能量无意义。

## 师兄提醒

!!! warning "Si 的带隙 0.6 eV 不是错"

    PBE/LDA 低估半导体带隙是 DFT 的著名系统误差（DFPT/杂化泛函/GW 才修）。看到 0.6 eV 别去"调参数修它"——**这是物理，不是 bug**。分清"计算的误差"和"理论的极限"，是计算物理入门的标志性一刻。

2. 把 `crystal_b` 路径改成 Γ-X-U-K-Γ-L-W-X，重跑对比（练习 k 路径书写）。
