# Ex3.3 DOS 与 PDOS：nscf + dos.x/projwfc.x

**本节目标：** 态密度是 DFT 结果的"第二张脸"。QE 算 DOS = nscf 上密网格 + dos.x；PDOS（轨道分辨）= projwfc.x——Wannier 链的投影分析也靠它。

## 1 流程

```
scf（不变） → nscf.in（均匀密网格 + nbnd 加倍） → dos.x → dos.dat
                                                 → projwfc.x → pdos_atm#... 文件
```

**nscf 和 bands 的区别**（Ex2.1 埋的问题）：nscf 用**均匀网格**（为积分 DOS），bands 用**路径**（为画线）。就这么简单。

## 2 nscf.in（关键差异三处）

```fortran
&CONTROL
  calculation = 'nscf'
  prefix      = 'si'
  outdir      = './tmp'
  pseudo_dir  = './pseudo'
/
&SYSTEM
  ibrav = 0
  nat = 2, ntyp = 1
  ecutwfc = 30
  ecutrho = 240
  occupations = 'fixed'
  nbnd = 10              ! 空带给够，DOS 图才完整
/
&ELECTRONS
  conv_thr = 1.0d-8
/
ATOMIC_SPECIES
  Si  28.0855  Si.pbe-n-rrkjus_psl.1.0.0.UPF
CELL_PARAMETERS angstrom
  0.00 2.715 2.715
  2.715 0.00 2.715
  2.715 2.715 0.00
ATOMIC_POSITIONS crystal
  Si 0.00 0.00 0.00
  Si 0.25 0.25 0.25
K_POINTS automatic
  12 12 12  0 0 0        ! 比 SCF 更密的网格
```

## 3 dos.x 和 projwfc.x

```bash
# 总DOS
cat > dosx.in << EOF
&dos
  prefix = 'si'
  outdir = './tmp'
  fildos = 'si.dos.dat'
  Emin = -13, Emax = 10, DeltaE = 0.01    ! eV
/
EOF
dos.x -in dosx.in > dosx.out

# 投影DOS（按原子/轨道分解）
cat > projwfcx.in << EOF
&projwfc
  prefix = 'si'
  outdir = './tmp'
  Emin = -13, Emax = 10, DeltaE = 0.01
  filpdos = 'si'
  lwrite_overlaps = .false.
/
EOF
projwfc.x -in projwfcx.in > projwfcx.out
```

**输出：** `si.dos.dat`（E, DOS, 积分DOS）；`si.pdos_atm#1(S)_wfc#1(s)` 等（E, 每个轨道 m 的 PDOS 列）。

## 4 验收与分析

- [ ] 积分 DOS 在 E_F 以下 = 价电子数 8（**积分守恒是 DOS 正确性的硬检查**）；
- [ ] 带隙内 DOS=0，位置与 Ex3.2 能带一致（两条独立计算互验）；
- [ ] PDOS：Si 价带顶主要是 p 特征、带底 s 特征——和化学直觉对上。

**积分 DOS 检查是很多人漏掉的免费午餐**：数字不对= k 网格不够密或 DeltaE 太粗，立刻重算，别带着错 DOS 做分析。

## 5 本节总结

- nscf（密网格+空带）→ dos.x / projwfc.x 两件套；
- 积分 DOS = 价电子数 是硬校验；
- PDOS 的轨道分辨和 projwfc 的投影，就是你以后做 Wannier 投影选择时的先遣侦察（姊妹篇 LWTHW Ex4.1 的 PROCAR 分析，QE 版）。

## 师兄提醒

!!! note "projwfc.x 是 Wannier 投影的侦察兵"

    姊妹篇讲"投影怎么选"（LWTHW Ex4.1）：先看费米面附近态的轨道成分。QE 世界里这个侦察工作就是 `projwfc.x` 的 PDOS。**两个软件在这里的能力一一对应**：PROCAR ≈ PDOS，`LORBIT=11` ≈ `projwfc`。工具会换，方法论不换。
