# Learn QE the Hard Way

**Learn Quantum ESPRESSO: The Hard Way** —— 华语圈最接地气的 QE 手把手入门教程。

本站风格复刻自大师兄的 [Learn VASP: The Hard Way](https://lvaspthw.readthedocs.io/en/latest/)，致敬，感谢先行者。

## 通知

**2026_11_22:** 网站第一版上线。5 章 18 页，从 pw.x 输入哲学到 Wannier90 接口。

1）想加内容？去 GitHub 仓库提 [Issue](https://github.com/pauli589/Learn-QE-the-Hard-Way/issues)。

2）对某块内容很熟？欢迎写经验进书中，提 PR。

3）家族齐全了：QE（本书）→ [Wannier90](https://pauli589.github.io/Learn-Wannier90-the-Hard-Way/) → [WannierTools](https://pauli589.github.io/Learn-WannierTools-the-Hard-Way/)。**QE 是这条工具链的最上游**——你的 hr.dat 质量上限，在 pw.x 那一刻就决定了。

## 这本书适合谁

- 组里主力是 VASP，但需要用 QE（接口、赝势、特定功能）的人；
- 拿着别人的输入文件改改能跑、报错了两眼一抹黑的人；
- 要走 `pw.x → pw2wannier90 → wannier90` 链的人——这条链的每一步坑本书都踩过。

## 这本书不适合谁

- 想要"复制粘贴出论文"的人；
- 第一性原理零基础的人（本书不讲 Kohn-Sham 方程，去读教科书）。

## 怎么用这本书

Chapter 1-2 吃透 pw.x 输入（QE 的全部日常就在这一个文件里）；Chapter 3 硅全流程实战；Chapter 4 后处理与进阶（含 Wannier90 接口——两本姊妹篇的上游）；Chapter 5 急诊室和瞎扯。每章末尾照例有**总结 / 师兄提醒 / 练习**。
