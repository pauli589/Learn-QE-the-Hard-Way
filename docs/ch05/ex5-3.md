# Ex5.3 瞎扯：赝势不是魔法

**本节目标：** 全书最后一页，不讲参数。讲一个 QE 用户（其实是一切 DFT 用户）迟早要过的心理关。

## 1 你算的从来不是"真实体系"

平面波赝势 DFT 算的是：**价电子 + 赝波函数 + 某个交换关联泛函近似**。三重近似层层叠：

- 赝势：芯电子+核的处理是"人为设计"的（Ex2.5 说过，换赝势=换模型的一部分）；
- 泛函：PBE 的带隙低估、范德华缺失、强关联失效——都是已知边界；
- 数值：ecut、k 网格、smearing，收敛了也只是"这套设置的极限"，不是"物理的极限"。

这不是要你虚无，而是要你**给自己的每个结论标定效力范围**：这个数在什么近似下、收敛到什么精度、和什么对照过。姊妹篇的门禁体系（WT 书 Ex8.5）逼 AI 做的，就是这件事——人也应该做。

## 2 软件是船，物理是海

三本书讲了一堆工具：pw.x、wannier90.x、wt.x。但工具会过时（QE 7→8、W90 4.0、WT 3.0），不变的是问题：

- 这个材料的低能物理由哪些态/轨道承载？
- 能带交叉/带隙/响应背后是什么对称性和杂化？
- 我的数值结论离"可信"差几步，分别是什么代价？

**QE 的价值不是让你多会一个软件，而是给你工具链源头的完全控制权**：赝势你能定制、接口你能读源码、错误你能查到底。控制权在手，物理问题才真正属于你。

## 3 The Hard Way 的最后一次总结

三本书，同一段话：

1. **上游决定一切**——SCF 质量、赝势选择、k 收敛，是下游一切结论的地基；
2. **验收是习惯不是任务**——七查、四查、三关，变成肌肉记忆；
3. **每个数字都能回答"从哪来"**——版本、参数、容差、对照，三个月后依然答得上来。

做到这三条，工具是你的仆人；做不到，你是工具的人质。

祝科研顺利。

—— 师兄

## 练习（全书最后一题）

为你的正式体系写一页"计算宪法"：结构来源与验收、赝势版本与三查结果、截断/k 网格收敛数据、能量参考约定、下游交接清单。以后每个新计算开工前翻一遍宪法——这一页纸，就是你从"QE 用户"到"DFT 研究者"的成人礼。
