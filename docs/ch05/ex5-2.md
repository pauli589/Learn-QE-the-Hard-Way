# Ex5.2 集群与并行：-nk 的正确用法

**本节目标：** QE 的三级并行体系。配对了快几倍，配错了慢几倍还可能崩——这页是花钱买来的经验。

## 1 三级并行

| 层级 | 开关 | 并行什么 | 什么时候用 |
|---|---|---|---|
| **k 点并行** | `-nk N` | 不同 k 点分给不同组 | **首选**：k 点多时扩展性最好 |
| 平面波并行 | `-npool` 之内默认 | FFT/波函数按板切分 | 基础层，总核数 = nk 组 × 组内核 |
| **对角化并行** | `-nd N` | 单次对角化拆分 | 仅"k 点少、单点极贵"时 |

```bash
# 典型命令：128 核，8 个 k 组
mpirun -np 128 pw.x -nk 8 -in scf.in > scf.out
```

## 2 配置规则

- **总核数必须被 -nk 整除**：`-nk 8` 配 128 核 → 每组 16 核；
- **-nk 不能超过 k 点数**（约化后的实际 k 点数，看输出 `number of k points`）；
- **每组核数不宜太少**（< 8 时 FFT 通信开销吃掉收益）；
- 2D 材料 k 点少（如 12×12×1 约化后 ~60 点），`-nk` 上限就是几十，别硬分。

## 3 串行任务别浪费

后处理（dos.x/projwfc.x/bands.x）大多串行或弱并行：

```bash
dos.x -in dosx.in          # 直接单核跑
```

用 `mpirun -np 64` 跑串行程序 = 64 核排队干一个人的活，还可能崩。

## 4 PBS 提交模板（结合你的集群习惯）

```bash
#PBS -l nodes=1:ppn=56
#PBS -l walltime=24:00:00
#PBS -j oe
cd $PBS_O_WORKDIR
module load q-e/7.2
NP=$(wc -l < $PBS_NODEFILE)
mpirun -np $NP pw.x -nk 7 -in scf.in > scf.out 2>&1
echo "exit code: $?" >> scf.out
```

（56 核节点、7 个 k 组的示例——按你的队列规则改；姊妹篇 WT 书 Ex1.3/手册强调的"退出码落盘、不用 & 掩盖失败"同样适用于 QE。）

## 5 性能 sanity check

跑大任务前先做一个 5 分钟的缩比测试（如 1/4 体系），对比 -nk 4 vs 8 的耗时——**扩展性不是想出来的，是测出来的**。k 点并行收益随体系/k 密度变化，没有万能配置。

## 6 本节总结

- 三级并行：k 点组（首选）/ 平面波（基础）/ 对角化（特殊）；
- 总核 = 组数×组内核，组数 ≤ k 点数，组内核 ≥ 8；
- 后处理别乱上核；提交脚本带退出码。

## 师兄提醒

!!! warning "walltime 按你的集群习惯给足"

    姊妹篇的原则直接搬过来：常规计算 walltime ≥ 24h，长任务（弛豫/大响应）给 48h，宁可余量不要撞墙。QE 的 SCF 步数不可精确预知，**卡在 99% 时被杀是最冤的死法**。
