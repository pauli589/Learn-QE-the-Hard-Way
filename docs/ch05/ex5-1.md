# Ex5.1 常见报错急诊室

**本节目标：** QE 高频报错速查。老规矩：先查这里，再问人。

## 找错误的万能入口

QE 输出很长，但报错一定在分隔符之间：

```bash
grep -B2 -A8 '%%%%' scf.out
```

十秒钟定位。没有 `%%%%` 就是没报错（但有可能是"错而不报"——那是另一回事，去各章验收清单）。

## 症状速查表

### ① `Error in routine read_namelists (5012)` / namelist 相关

**病因：** namelist 语法错——少引号、少逗号、没闭合 `/`、参数名拼错。
**药方：** 对照 Ex1.3 的骨架；不认识的参数名去官方 INPUT_PW 查（QE 对不认识的参数名直接崩，不装糊涂——这点比 VASP 诚实）。

### ② `file ... not found` / `charge density ... not found`

**病因：** ① 赝势路径（pseudo_dir）；② 上游产物找不到（prefix/outdir 不一致）。
**药方：** 逐一核对三个路径；NSCF/bands 确认 prefix 与 SCF 完全一致。

### ③ `Sym. Ops. not allowed with more than ... k-points`（NSCF 报）

**病因：** Wannier 链的 NSCF 没关对称性，显式 k 点和对称性冲突。
**药方：** `nosym=.true., noinv=.true.`（Ex4.4 的三★配置）。

### ④ `not enough space` / 内存爆

**病因：** nbnd 太大、体系太大、并行配置不当。
**药方：** 减 nbnd（检查是否给了不必要的空带）；用 `-nk` 分 k 点组（Ex5.2）；加大节点内存。

### ⑤ SCF `convergence NOT achieved`

**病因/药方：** 见 Ex2.3 的完整排查树。最常见前二：金属没给 smearing；mixing_beta 太大。

### ⑥ `SLVM`/`cholesky` 类对角化报错

**病因：** 波函数线性依赖（ecutrho/赝势不匹配、结构原子重叠、初结构太差）。
**药方：** 查结构合理性；查 ecutrho 与赝势推荐值；换 `diagonalization='cg'` 试。

### ⑦ 力/应力巨大，结构乱飞

**病因：** 赝势与元素不匹配（张冠李戴）、ecutrho 隐形杀手、初结构原子重叠。
**药方：** grep UPF 文件头三查（Ex2.5）；打印初始一步 SCF 看力是否合理量级。

### ⑧ 能量对不上文献/另一个软件

**按顺序查：** 单位（Ry→eV ×13.6057）→ 泛函一致吗 → 赝势同款吗 → k/ecut 收敛了吗 → 绝对能量本来就不该比（只比相对量，Ex3.2）。

## 就诊流程

```
出问题
 ├─ 1. grep '%%%%' 定位报错段 → 本表对症
 ├─ 2. "错而不报"类 → 各章验收清单（Ex3.1 七查 / Ex4.4 四查）
 └─ 3. 问人/提 Issue 的姿势：完整输入 + 报错段 + 版本/编译信息
```

## 师兄提醒

!!! warning "提问的艺术（三书统一版）"

    合格求助 = 一句话症状 + 完整输入文件 + 报错段 + `pw.x` 版本/编译方式。别只发一句"QE 跑不出来"——帮你的人会需要反问三轮才能开始诊断，浪费的是双方的生命。
