# Ex1.3 输入文件哲学：一个前缀走天下

**本节目标：** 吃透 QE 输入文件的"世界观"。这页懂了，后面所有参数都是填充题。

## 1 唯一的输入文件

QE 的日常输入是**一个纯文本文件**喂给 `pw.x`：

```bash
pw.x -in scf.in > scf.out
```

结构 = **三个 namelist + 一串卡片**：

```fortran
&CONTROL                 ! ① 你要干什么（任务类型、文件名）
  calculation = 'scf'
  prefix      = 'si'
  outdir      = './tmp'
/
&SYSTEM                  ! ② 体系是什么（晶胞、电子、截断）
  ibrav = 2
  celldm(1) = 10.2
  nat = 2, ntyp = 1
  ecutwfc = 30
/
&ELECTRONS               ! ③ 怎么收敛（ mixing/smearing 精度）
  conv_thr = 1.0d-8
/
ATOMIC_SPECIES           ! ── 以下卡片：具体数据 ──
Si  28.0855  Si.pbe-n-rrkjus_psl.1.0.0.UPF
ATOMIC_POSITIONS
Si 0.00 0.00 0.00
Si 0.25 0.25 0.25
K_POINTS
automatic
8 8 8 0 0 0
```

**记忆法：先回答三个问题（干什么/是什么/怎么收敛），再给数据（原子/结构/k 点）。**

## 2 prefix + outdir：QE 的"工作目录身份证"

- `outdir`：QE 的临时仓库（波函数、电荷密度都存这）；
- `prefix`：仓库里文件的姓（`si.save/`、`si.xml`……）。

**NSCF、后处理都要读上一步的结果**——它们通过**相同的 prefix + outdir** 找到上一步的产物：

```fortran
# 能带计算（读 SCF 的密度）
&CONTROL
  calculation = 'bands'
  prefix      = 'si'          ! 必须和 SCF 一模一样
  outdir      = './tmp'
/
```

`prefix` 对不上，QE 报"charge density not found"——这是新手第一大报错，你现在知道根因了。

## 3 卡片五杰

| 卡片 | 给什么 | 必写？ |
|---|---|---|
| `ATOMIC_SPECIES` | 元素、质量、赝势文件 | 是 |
| `ATOMIC_POSITIONS` | 坐标（`crystal`/`alat`/`angstrom` 单位可选） | 是 |
| `CELL_PARAMETERS` | 晶格矢量 | ibrav=0 时必写 |
| `K_POINTS` | k 网格或列表 | 是 |
| `OCCUPATIONS` | 手动占据 | 特殊体系 |

## 4 单位制：QE 默认 Ry 原子单位

- 能量：Ry（**1 Ry = 13.6057 eV**，别和 VASP 的 eV 混）；
- 长度：bohr（alat 单位下）；但 `ATOMIC_POSITIONS angstrom` 和 `CELL_PARAMETERS angstrom` 可显式指定；
- **每次从 QE 拿能量数据去和别的软件对比，先乘 13.6057**——单位错位是 QE/VASP 混用者的经典错账（姊妹篇 WT 书 Ex8.4 的老话题，源头就在这）。

## 5 本节总结

- 一个文件 = 三个 namelist（干什么/是什么/怎么收敛）+ 数据卡片；
- `prefix + outdir` 是跨步骤传递数据的钥匙；
- QE 默认 Ry，换算 13.6057 刻烟吸肺。

## 师兄提醒

!!! warning "自由格式的代价"

    QE 输入对缩进/顺序宽容，但** namelist 里的引号（'scf'）和数据卡片的关键词（automatic）不能错**。报错时先看是不是 namelist 没闭合（缺 `/`）——新手第二大报错，配额管够。
