# Ex1.1 QE 是什么，和 VASP 什么关系

**本节目标：** 给从 VASP 世界过来的你一张 QE 地图——它是什么、强在哪、和 VASP 怎么分工。

## 1 一句话定位

Quantum ESPRESSO（QE）：**开源平面波赝势 DFT 套件**，意大利出产，社区维护三十年。核心程序 `pw.x`（自洽+能带），外围一堆 `*.x` 后处理。

和 VASP 的关系一句话：**同类竞品，开源 vs 商业，生态不同**。物理内核都是平面波 + 赝势 + Kohn-Sham，你会的 DFT 概念全部平移。

## 2 为什么你的工具链需要 QE

明知组里主力是 VASP，还要学 QE 的三个现实理由：

1. **Wannier90 接口最成熟**：`pw2wannier90.x` 是历史最久、文档最全的 W90 接口（姊妹篇/WT 书的全链教程都以 QE 为例）；
2. **赝势自由**：VASP 的 PAW 数据集闭源限量，QE 的赝势库（PSlibrary）开源、可自己生成——你项目里"定制 d-zeta 赝势"这类操作只有 QE 玩得转；
3. **可读源码**：报错诡异到极点时，开源软件你可以翻 Fortran（VASP 只能发邮件等回复）。

## 3 QE vs VASP 速查表

| | VASP | QE |
|---|---|---|
| 输入 | INCAR 标签 | Fortran namelist + 卡片 |
| 输出 | OUTCAR 等 | 标准输出（又长又直白） |
| 赝势 | PAW（内置库） | 赝势文件（PSlibrary/自制） |
| k 点 | KPOINTS 文件 | 输入内 `K_POINTS` 卡片 |
| 后处理 | vasprun.xml + 外部工具 | `*.x` 自带全家桶 |
| 价格 | 商业授权 | **免费开源** |
| 中文教程 | 多（大师兄） | 少而散（→本书） |

**思维转换提示：** VASP 用户最容易犯的错是把 QE 当"另一个 VASP"逐参数翻译。别。QE 的参数体系、收敛控制、后处理逻辑自成一套，从零按本书走一遍，比逐条翻译快得多。

## 4 QE 套件地图（常用的）

| 程序 | 干什么 |
|---|---|
| `pw.x` | SCF / NSCF / 能带 / 结构优化（90% 的日常） |
| `pw2wannier90.x` | Wannier90 接口（Ex4.4） |
| `dos.x` / `projwfc.x` | 态密度 / 投影态密度 |
| `pp.x` | 电荷密度/势/波函数导出 |
| `bands.x` / `plotband.x` | 能带整理与画图 |
| `ph.x` / `dynmat.x` | 声子（本书不覆盖） |
| `cp.x` / `car-parinello` | 分子动力学（本书不覆盖） |

## 5 本节总结

- QE = 开源平面波 DFT，概念与 VASP 全通，语法体系全新；
- 学它的三大理由：W90 接口、赝势自由、源码可读；
- 90% 的日常就是 `pw.x` + 几个后处理 `*.x`。

## 师兄提醒

!!! note "别在两个软件间'逐字翻译'"

    VASP 的 `ENCUT` 对应 QE 的 `ecutwfc`，但收敛行为不同（QE 还有 `ecutrho`，且对 USPP/PAW 敏感）；VASP 的 `ISMEAR` 对应 `occupations`，但选项体系完全不同。**按本书从零学，学完自然知道对应关系**；反过来逐条硬翻，两头都是坑。
